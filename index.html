AutoTube

A private, single-user publishing tool for the owner's own YouTube channel

What AutoTube does

AutoTube is a personal automation tool run by the owner of the Curious Minute YouTube channel. Each day it:

  • looks at publicly available trending topics (Google Trends, Wikipedia, and similar public sources);
  • writes a short educational script grounded in a cited public source (Wikipedia) and fact-checks it;
  • assembles a vertical video from openly licensed images, a synthetic narrator voice and original music;
  • uploads the video to the owner's own YouTube channel and schedules its publication;
  • reads that channel's own view and audience-retention statistics to decide which topics and formats to make next.

How it uses Google data

AutoTube uses the YouTube Data API and YouTube Analytics API, authorized only by the channel owner, with these permissions:

  • youtube.upload: to upload videos to the owner's channel;
  • youtube.readonly: to read the owner's channel and video details (for example, view counts);
  • yt-analytics.readonly: to read the owner's channel analytics (for example, average view percentage).

AutoTube is not offered to the public, has no user accounts, and never accesses anyone else's Google or YouTube data.
