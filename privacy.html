Curious Minute Publisher Privacy Policy

Last updated: September 24, 2026

Curious Minute Publisher ("the app") is a private, single-user tool operated by the owner of the Curious Minute YouTube channel to create and publish videos on that same channel. This policy explains what data the app accesses and how it is handled.

1. Who can use the app

Only the channel owner. The app is not offered to the public, has no sign-up, and does not collect data from other people.

2. Google user data accessed

With the owner's explicit authorization through Google OAuth, the app accesses:

  • YouTube upload access (youtube.upload): used only to upload videos the app has produced to the owner's channel and to set their title, description, tags and scheduled publish time.
  • YouTube read-only access (youtube.readonly): used only to read the owner's own channel and video details, such as video IDs, privacy status and view, like and comment counts.
  • YouTube Analytics read-only access (yt-analytics.readonly): used only to read aggregate statistics for the owner's own videos, such as views, average view duration and average view percentage.

The app does not access the owner's Gmail, contacts, files or any other Google data, and it never accesses other users' data.

3. How the data is used

Channel statistics are used solely to decide which topics, formats and styles the app should produce next. The data is not used for advertising, not sold, not shared with or transferred to third parties, and not used to train AI models.

4. Storage and retention

  • The OAuth credentials (client ID, client secret and refresh token) are stored as encrypted secrets in the owner's private GitHub repository and are never published.
  • A small log of the channel's own video IDs, titles and performance numbers is kept in the owner's private repository so the app can learn over time. The owner can delete it at any time.
  • These statistics are refreshed from the YouTube API nightly, which also re-confirms that access is still authorized. If a video is deleted from YouTube, its stored statistics are removed on the next refresh, and any statistics not re-verified within 30 days are deleted.
  • If the owner revokes access (see section 5), the app can no longer read or refresh any data. Stored statistics can be deleted by removing the log file from the private repository.
  • No personal data about viewers is collected or stored.
  • Cookies: this website and the app do not place, read or recognize cookies or similar technologies on your device, and do not allow third parties to serve content or advertisements.

5. Revoking access

The owner can revoke the app's access at any time at myaccount.google.com/permissions, and via the Google security settings page. Revoking access immediately stops all uploads and analytics reads.

6. Google API Services User Data Policy

Curious Minute Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. YouTube API Services

Curious Minute Publisher uses YouTube API Services. By using the app, the owner agrees to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.
